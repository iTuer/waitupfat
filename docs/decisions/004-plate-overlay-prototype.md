# ADR-004：餐盘遮挡与照片交互样机

日期：2026-11-03（Asia/Shanghai）。状态：本轮 UI 样机范围由用户明确；不等同正式应用功能发布。

## 决定

- 单页逐步试样式，不采用此前提出的“今天／回顾／设置”三页，不启动用餐计时流程。
- 大白板默认遮挡餐盘，承载所选餐次信息；手动下拉露出的餐盘，打开完整餐盘浮窗，下面内容模糊。保留直接展开按钮作为替代入口。
- 餐盘使用本轮生成的写实白瓷素材；用户上传的真实图片按餐次扇形裁剪，支持拖动、缩放、重新裁剪和点击查看原图。
- 原图与裁剪图分开存入本机 IndexedDB。仅生成分享图片供用户自行下载，不自动发布；真实照片与私人导出不进入 GitHub。

## 实施与边界

独立样机：[plate-v1](../product/prototypes/plate-v1/index.html)。这是 UI 试用，不迁移线上应用数据，不连接 AI、账号、营养分析、云端同步或通知。照片按日期／餐次保存，清理浏览器数据会丢失本机记录。尚未做跨设备同步。

素材 plate.webp 由 imagegen 于 2026-11-03 生成，源文件位于本机生成目录；项目保存压缩副本。不是下载的第三方餐具照片，不作排他版权保证。

验证：本地浏览器实走下拉展开、真实文件选择、扇形裁剪保存、刷新后恢复、查看原图、删除试传图和分享图片生成／下载；修正浮窗焦点滚动及旋转 SVG 透明区域遮挡按钮。使用生成餐盘素材作测试文件，不使用个人餐照。窄屏实际手机触摸与系统相册兼容性仍待用户试用。

回退：继续使用旧演示或既有线上应用即可；本轮没有生产数据库或业务部署变更。旧布局评估和提案保留追溯，不能视为当前已采纳的页面结构。
