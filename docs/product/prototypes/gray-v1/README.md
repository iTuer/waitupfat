# 当前餐食灰版 v1

2026-11-04（Asia/Shanghai）。这是单页、可交互的灰度原型，用于核对结构与操作。默认白板遮挡餐盘，顶部计时、当前餐食信息、侧边陪吃角色和底部停止按钮属于同一条记录。没有固定三餐分类或新增导航页面。

可试：日期入口与月历、下拉餐盘、真实照片选取及形状裁剪、原图查看、拖动／展开／关闭陪吃小人、“放下筷子”停止当前计时。角色使用原创 SVG 灰色占位动画；不借用截图中的角色，不显示虚构的咀嚼检测计数。

计时与停止为当前打开会话的交互演示，刷新会重置；照片单独保存在本机 IndexedDB，不上传网络。此灰版不连接 AI、营养评价或生产账号。月历为灰版自绘交互占位，尚未正式选定第三方日历库。

依赖相邻 plate-v1/plate.webp，运行本地静态服务后打开 gray-v1/。继承原照片交互；浏览器核对日期弹层、陪吃展开和停止状态，脚本语法通过。本轮不是应用部署。
