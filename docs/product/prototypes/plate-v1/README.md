# 餐盘交互样机 v1

本地静态服务打开 index.html。资源 plate.webp 必须位于同一目录；勿使用 file:// 方式测试本机照片保存。

默认白板遮住餐盘；下拉餐盘或点右上展开按钮查看完整盘子。记录没有早餐／午餐／晚餐分类，按实际添加的记录与时间显示；餐盘分区随记录数量变化。可切换日期、添加记录、上传真实图片，拖动与缩放后按分区形状裁剪；点击缩略图或“查看原图”查看原始照片。浮窗内可生成并下载餐盘 PNG。

照片只保存于本机浏览器 IndexedDB，同一来源下刷新可恢复；不上传服务器。清理浏览器数据或更换浏览器会失去记录。无 AI 识别、营养评分、用餐流程或云端同步。

plate.webp 为本轮 imagegen 生成的白瓷盘，经尺寸缩减和 WebP 编码；不是第三方产品照片。没有打包用户餐照、私人导出或截图。

设计依据与验证记录：[ADR-004](../../../decisions/004-plate-overlay-prototype.md)。样机独立于已部署 v0.1.0。
