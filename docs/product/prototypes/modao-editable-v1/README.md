# 墨刀可编辑原型源文件 v1

2026-11-05。更正上一轮整页图片包的交付形式，保留静态灰版 v2 的六个状态与布局，不新增功能。

## 首选：导入 Sketch 源文件

文件：`meal-states-editable.sketch`。

在墨刀工作台选择「新建墨刀原型」旁的下拉菜单 →「导入为墨刀原型」→ Sketch，选择本目录的 `.sketch` 文件。文件含一页、六张 390×844 画板。文字是独立文本图层；餐盘、照片占位、按钮、评分条、背景与分隔线分别是形状图层，可调整大小、位置、颜色、字体和内容。当前不含交互连线，不把静态稿误称为运行中的产品。

依据：[墨刀三方文件导入](https://modao.cc/hc/articles/330)、[Sketch 官方文件格式](https://developer.sketch.com/file-format/)。Sketch 文件按公开 JSON 格式生成，不是将图片改扩展名。未使用整页位图或将文字转成轮廓；餐盘浮窗背景组可展开编辑。模糊效果未写入 Sketch 背景组，以保留简单的可编辑结构，必要时在墨刀内补设。

## 备用：HTML 转可编辑原型

同目录六份 HTML 每个可见元素均独立，绝对坐标布局，无脚本、Canvas、整页图片或网络资源。`layers.json` 列出每个状态的元素。走墨刀的「HTML 转原型」能力；普通 HTML 不应放进 Axure 文件导入入口。官方能力入口参考 [墨刀更新记录](https://modao.cc/changelog)、[HTML 导入工具说明](https://modao.cc/feature/ai-mcp.html)。

## 验证边界

HTML 已检查独立元素结构并在本机渲染默认状态，布局与上一轮一致。Sketch 已通过官方 JSON Schema（@sketch-hq/sketch-file-format 6.5.0）校验，并核对 ZIP／JSON 结构：6 张画板，161 个独立文字图层、158 个独立形状，无位图层。未在用户墨刀账号内实际导入，不宣称墨刀转换后的每个元素和视觉效果均已验证；导入后应抽查文字修改、形状拖动、评分条缩放与画板裁切。源文件中所有分数与食物仅为布局示例，无真实餐照或用户数据。此交付不改变线上应用或数据库。
