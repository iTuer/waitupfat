# 产品方案

当前方案：[v0.2.0 完整产品方案](versions/v0.2.0.md)，2026-10-26。

产品名称：嘴巴等等我。方向：每日三餐安排与记录，额外想吃通过公开审批获得建议，再回填实际决定，形成长期饮食观察。

方案已归档不等于功能已上线。当前应用仍为 v0.1.0，使用“所有公开饮食记录参与审批”的旧规则；新版三餐免审批、截止结算、记录分和 AI 陪伴等按 [实施清单](ROADMAP.md)推进。
