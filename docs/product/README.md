# 产品方案

当前方案：[v0.3.0 拍照优先 MVP](versions/v0.3.0.md)，2026-10-27。

产品名称：嘴巴等等我。下一版先验证拍照／选图、自动识别、用户纠错和确认保存；额外想吃的审批保留为可选支线。

方案已归档不等于功能已上线。当前应用仍为 v0.1.0，使用“所有公开饮食记录参与审批”的旧规则；拍照识别尚未实现；按新[实施清单](ROADMAP.md)推进，三餐计划、评分和复杂审批延后。

| 方案版本 | 日期（上海） | 变化 | 状态 |
|---|---|---|---|
| [v0.3.0](versions/v0.3.0.md) | 2026-10-27 | 拍照优先、自动整理与纠错，缩减首版手填与管理负担 | 当前设计基线，待实施 |
| [v0.2.0](versions/v0.2.0.md) | 2026-10-26 | 第一个完整产品方案；明确三餐／额外审批分离、上下文、评分、隐私、AI、阶段范围 | 历史基线，实施优先级已调整 |
