# 产品方案

最新方案：[v0.4.0 完整优化提案](versions/v0.4.0.md)，2026-10-28；待评审，未实施。此前明确的拍照优先方向保留，见 [v0.3.0](versions/v0.3.0.md)。

产品名称：嘴巴等等我。先验证拍照／选图、自动识别、纠错与确认保存。v0.4.0 建议后续社交改为具体候选帮选，再验证收藏与付费 AI 回顾安排；帮选替代审批属于待确认的产品变更。

方案已归档不等于功能已上线。当前应用仍为 v0.1.0，使用“所有公开饮食记录参与审批”的旧规则；拍照识别尚未实现；按新[实施清单](ROADMAP.md)推进，三餐计划、评分和复杂审批延后。
